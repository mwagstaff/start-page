## Design Context

### Users
People using tab1.net as a personal start page to scan stories, open articles and
comments, search, and check the weather. Keyboard access is a first-class use case.

### Brand Personality
Compact, clear and polished. Preserve the existing news-card layout and logo.

### Aesthetic Direction
The user requests upright shortcut badges with the existing slanted 1 logo's
blue/violet gradient and highlights. Use a soft glow to identify keyboard focus.
Keep the default view quiet; disclose story-letter hints after a card-number key.
Support the existing light/dark themes and background-photo choices.

### Design Principles
- Keep keyboard and mouse access equally usable, with native links and controls.
- Reserve space for badges; never cover labels, story text or thumbnails.
- Reveal contextual instructions when relevant instead of showing every hint.
- Preserve visible focus, reduced-motion support and shortcut opt-outs.
- Use the site's existing visual language rather than introducing a new theme.
